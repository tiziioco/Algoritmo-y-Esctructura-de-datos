# 📚 Proyecto: Gestión de Biblioteca Personal

## 📌 Descripción
Este proyecto es un sistema simple en Python que permite gestionar una biblioteca personal.  
Integra los temas vistos en clase:
- *Matrices (listas de listas):* para guardar los detalles de cada libro.
- *Tuplas:* para identificar libros de manera única (título, autor).
- *Diccionarios:* para asociar cada libro con sus datos.
- *Conjuntos:* para mostrar géneros sin repetición.

## 🚀 Funcionalidades
- Agregar libros con título, autor, año, género y estado.
- Mostrar toda la biblioteca.
- Marcar libros como leídos.
- Listar libros según su estado (leído o pendiente).
- Ver todos los géneros disponibles.
